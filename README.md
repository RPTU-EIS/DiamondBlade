# DiamondBlade
This repository contains the case studies and the DiamondBlade Python Tool mentioned in the DiamondBlade paper [1].
## Repository Structure
The case studies directory contains the four case studies that were conducted using the DiamondBlade methodology.
Each folder contains the needed Register-Transfer-Level(RTL) files and the proven properties as well as a TCL script to setup the verification environment with the OneSpin Software.

The DiamondBlade Python Tool source files as well as a description of how to use it are contained in the corresponding directory.
